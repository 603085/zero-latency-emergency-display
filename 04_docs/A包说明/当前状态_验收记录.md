### ⭐ 关键结论：两个负的**都不是我们的代码**

把每一条违规路径的**端点**列出来看过了：

**`sd_card_clk`（−0.665，3 个端点）**
```

sd_card_bmp_m0/bmp_read_m0/mux55                              ← 例程
sd_card_bmp_m0/bmp_read_m0/scan_done_reg                      ← 例程
```

**`ext_mem_clk`（−6.699 / −0.591）**
```
U3/sdram.*                          ← SDRAM 硬核（加密）
sd_card_top/spi_master/MOSI_shift   ← 例程
frame_read_write_m0/frame_fifo_*    ← 例程
```

**`text_layer` / `layer_mixer` / `mode_fsm` / `scroll_timer` / `uart_rx` / `uart_text` /
`video_layers_top` —— 一条都没有。**

`ext_mem_clk` 的 −6.699 **从项目第一天就在**，而板子一直正常工作。
`sd_card_clk` 在 ±0.7 ns 之间随布局浮动（上一次布局是 +0.161）。
